# Security Policy

## Supported Versions

Security fixes are applied to the latest version only. We do not backport patches to older releases.

## Reporting a Vulnerability

We take security issues seriously. If you think you've found something, please report it privately rather than opening a public GitHub issue. Doing so gives us a chance to fix it before it becomes a problem for users.

**Contact:** security@zentral-hack.ch

Please include as much detail as you can: steps to reproduce, potential impact, and any relevant logs or screenshots. We'll acknowledge your report within a few business days and keep you in the loop as we work through it.

We appreciate responsible disclosure.
